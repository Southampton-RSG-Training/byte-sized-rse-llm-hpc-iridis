# Fine-Tuning LLMs with HPC

This is a byte-sized course which covers the basics of fine-tuning tasks using large language models. In addition to the basics of using the Transformers library to perform inference and common fine-tuning tasks, the course shows how to use SLURM and MPI in conjunction with the Accelerate library to run fully-sharded data parallel training across multiple nodes and GPUs.

This course assumes some familiarity with Python, PyTorch, Accelerate, SLURM, as well as concepts associated with large language models and their architectures.
